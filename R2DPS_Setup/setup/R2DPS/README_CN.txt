R2DPS 1.0.0 —— 遗迹2（Remnant II）伤害统计 mod（UE4SS Lua，只需房主装）
https://github.com/OzakiJUN/Remnant2-DPS-Meter


【安装】
用安装包里的 Install.bat 一键安装 / 更新（自带 UE4SS，已装的 UE4SS 太旧时提示升级，更新时保留你的设置）。
手动安装：先装好带 LoopInGameThreadWithDelay 的 UE4SS（v3.0.1-1181 或更新的 experimental 版），
再把整个 R2DPS 文件夹放进 ue4ss\Mods，文件夹里带了 enabled.txt，会自动加载。

【怎么用】
- 小 HUD：右上角小地图下面（避开了"可用特性点"这类提示）。第一行是战斗标签（BOSS 红 / 精英 橙 / 普通 灰）、
  标题和战斗时间；下面每人一行：背后的色条 = 伤害占比，大字 = 实时 DPS（最近 5 秒），小字 = 总伤害和占比。
  不能点，不挡鼠标。
- 详细面板（屏幕左边、队友头像下面，只能看不能点）：
    点一下 H   面板一直开着，再按一下 H 关掉
    按住 H     按着时显示，松开收起
  多人时显示全队总览，单人时显示自己的明细（config.txt 里 hold_page = self 可改成总是看自己）。
- Tab 菜单 → 碎片页：右上角"伤害统计"小卡片，点一下展开，占满右边一栏：
    收起              收起面板（收起后右边恢复可点）
    < 上一场 / 下一场 >  翻历史（只保存顶上亮血条的 boss / 精英战），下面的小点表示第几场
    顶上的页签        总览 / 每个玩家一页（单人时没有页签）
    总览页点玩家名    跳到那个人的页
  总览页：伤害占比、每人各项数据对比（每项最好的标金色）、每人的伤害构成、全队 DPS 曲线（按人分色叠起来）。
  个人页：DPS / 暴击率 / 弱点率 / 最高单发，倒地 / 被救 / 救人 / 阵亡 / 治疗 / 承伤，
  伤害构成（每类一个颜色，条里暗色那段是持续伤害），每类前几名来源，个人 DPS 曲线。
  菜单其他页不显示。
  面板卡住关不掉时（比如开着菜单切出去再回来），关掉菜单再打开一次就好。
- 颜色：长枪橙、手枪黄、近战红、改装蓝、技能紫、召唤绿、其他灰；你自己金色，队友蓝 / 红 / 绿。
  都能在 config.txt 里改（#RRGGBB）。
- 动画（面板滑入、进度条生长、数字滚动、鼠标悬停高亮）：只在有东西在变或面板打开时才刷新，
  觉得多余可以在 config.txt 里 animations = 0 关掉。

【MVP 和趣味称号】
- 评分：每项先算"你占全队的比例"，加权后乘以人数，全队平均正好是 100 分（150 = 比平均高一半）。
    输出 55%（伤害占比）  救人 20%（扶起队友的次数）  治疗队友 10%（给别人回的血，自己回血不算）
    生存 15%（倒地、阵亡越少越高，阵亡按两次倒地算）
  全队都没人救人 / 治疗时，那部分权重算到输出里。
- MVP = 评分最高的人。单人、或者不到 15 秒的普通战斗不评。
  总览页对比表第一行是评分，MVP 名字旁边有金色 MVP 标签；boss / 精英战打完，HUD 下面多一行显示 MVP。
- 称号：每场每人 3 个，挑最突出的。全队最好才拿的（金色）：输出担当、救火队员、奶妈、狙神、暴击狂人、
  一击入魂、爆发之王、肉盾；看打法的：召唤大师、持续伤害专家、改装达人、技能流、近战狂魔、手枪侠、
  长枪信仰、全能选手、精准射手、欧皇、毫发无伤、稳如泰山、越战越勇、开局爆发、全勤奖；
  搞笑的（红色）：躺平大师、气氛组、死而复生、到此一游。实在没有特点的补"打工人""默默耕耘"。
  单人也有称号，只是没有"全队最好"那一类。

【战斗怎么分场】
- 坐火、顶上血条出现、血条打完消失 → 当前这场结束。
- 坐火时如果是普通战斗，直接清零（HUD 消失）；boss / 精英战不清，留在历史里。
- 之后任何玩家第一次打到怪 → 新的一场开始，面板清零。
- 有血条的战斗用血条上的名字（游戏官中）做标题，标 [Boss] 或 [精英]（有词缀的算精英），存进历史，默认最近 10 场。
- 普通小怪战不进历史。
- 超过 5 秒没人造成伤害的空档不算战斗时间（config.txt 里 idle_gap 可改）。

【统计规则】
- 只算真正扣掉的血：溢出伤害不算（一发 495 打死只剩 158 血的怪，只算 158）。想算满额改 damage_mode = raw。
- 召唤物的伤害算到召唤者头上；改装、武器身上的流血 / 燃烧等持续伤害算到对应的改装 / 武器里，另外单独标出"其中持续"。
- 打到队友、打自己（比如召唤时扣的血）、打碎场景物件都不算。
- 承伤只算敌人和环境打的。
- 还没人打到怪之前就发生的挨打 / 倒地 / 阵亡 / 救人（比如被偷袭），算进紧接着开始的那一场（20 秒内）。
- 暴击率 / 弱点率只按直接命中算，不含持续伤害。

【名字显示】
武器、改装、技能、状态效果，游戏里只拿得到英文内部名（比如 TommyGun、ExplosiveShot、Bleed）。
names.txt 里按"英文名 = 中文名"对应，已经填了一批：标 [核实] 的是查到的官中，标 [暂译] 的是先翻译的，
看到和游戏里不一样的直接改。
打的时候遇到没填过的名字，会自动记到 R2DPS 文件夹里的 names_todo.txt，
把里面的行复制进 names.txt 填上中文，重开游戏生效。

【性能】
- 平时只挂 7 个函数，每次伤害只做几次加法；界面只改变化了的部分。
  动画只在有变化 / 面板打开时按 30 帧刷新，其余时间不额外占用。
- 安装包会帮你关掉 UE4SS 自己的调试窗口（UE4SS-settings.ini 里 [Debug] 的 ConsoleEnabled /
  GuiConsoleEnabled / GuiConsoleVisible = 0）和开发者调试 mod（KismetDebuggerMod / EventViewerMod），
  还会问要不要关掉 UE4SS 自带、R2DPS 用不到的 mod（BPModLoaderMod 等）。BP mod 加载器会在每个敌人、子弹、
  特效生成时跑一次脚本，推荐关；装了别的 BP mod（Content\Paks\LogicMods 里有 .pak）的话默认不关。
- 不想用了：删掉 R2DPS 文件夹里的 enabled.txt 就不加载。
- 安全模式：config.txt 里 ui_enabled = 0，只统计（写日志）不显示任何界面，也不查按键。
  万一又崩了，先开这个试，能分清是不是界面部分的问题。
- H 键是从游戏里读的，所以在菜单、聊天框里按不会触发（这是正常的）。

【联机】
- 只有房主装：游戏只把全队的伤害发给房主，所以房主的面板统计所有人。
- 你进别人的房间时 mod 自动停用（不挂钩子、不显示），回到自己当房主 / 单人时自动恢复。
- 倒地 / 被救 / 救人：用的是游戏的倒地组件事件，联机时请留意数字对不对。
- 按名字认人：队友退出再进来、换地图都还是同一行（两个人名字完全一样的话会被算成一个人）。

【遇到问题】
- 先看 R2DPS 文件夹里的 R2DPS_debug.txt（游戏装在中文路径下时，在 %LOCALAPPDATA%\Remnant2\Saved\Logs 里）。
- 闪退：先把 config.txt 里 ui_enabled 改成 0 试试；再把 ue4ss 文件夹里最新的 crash_*.dmp 和 R2DPS_debug.txt
  一起发到 GitHub 的 Issues（https://github.com/OzakiJUN/Remnant2-DPS-Meter/issues）。
- 发日志前别重开游戏：每次启动游戏，R2DPS_debug.txt 都会被清空重写。
- 想调位置 / 字号 / 热键 / 颜色：都在 config.txt，不用改代码。位置单位是 1080p 基准，2K / 4K 自动缩放。
