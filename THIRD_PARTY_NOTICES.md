## UE4SS (RE-UE4SS)

The release package (`R2DPS_Setup_v*.zip`) bundles an unmodified build of UE4SS
(`R2DPS_Setup/setup/ue4ss_bundle/UE4SS_v3.0.1-1181-g83330635.zip`), which the installer copies into the
game folder. R2DPS needs the game-thread timer `LoopInGameThreadWithDelay` that this build provides.
